# Transport – instalacije

Ovde su samo instalacije programa **Transport**: bez izvornog koda i bez ikakvih podataka. Instalirani program odavde
sam preuzima nove verzije i instalira ih kad se zatvori.

**Prva instalacija:** otvorite najnovije izdanje u delu **Releases**, preuzmite `Transport-Setup-….exe` i pokrenite ga.
Windows može da upozori „Windows je zaštitio vaš računar“, jer instalacija nije digitalno potpisana: kliknite **Više
informacija**, pa **Ipak pokreni**.

Uputstvo (PDF) je priloženo uz svako izdanje, a u programu se otvara dugmetom **📖 Uputstvo**.

---

Installers of the **Transport** program only: no source code, no data. The installed program downloads new versions
from here and installs them when it is closed. First installation: download `Transport-Setup-….exe` from the latest
release and run it (the installer is unsigned: *More info → Run anyway*).
